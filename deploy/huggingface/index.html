02 / Ingestion

De la donnée brute à l’index

01Analyse de la mise en page (Layout-Aware)

Transformation des PDF complexes en Markdown via IBM Docling ou PyMuPDF4LLM pour préserver la structure (tableaux, titres).

02Nettoyage en 8 étapes

Normalisation Unicode, suppression des en-têtes/pieds de page, correction OCR et nettoyage des tableaux ASCII.

03Chunking Sémantique

Découpage intelligent en morceaux de 512 tokens avec fenêtre glissante de 64 tokens pour ne jamais perdre le contexte.

04Vectorisation (Embeddings)

Conversion du texte en vecteurs mathématiques via Nomic Embed, stockés dans ChromaDB pour une recherche instantanée.

03 / Recherche

Recherche hybride

La recherche associe la proximité sémantique à la précision des mots-clés.

01Fusion RRF

Combine la Recherche Vectorielle (sens) et BM25 (mots-clés) via Reciprocal Rank Fusion pour un équilibre parfait entre sens global et précision technique.

02Re-ranking Cross-Encoder

Un modèle IA expert analyse en profondeur les 20 meilleurs candidats pour ne conserver que les plus pertinents avant la génération.

03RAG Agentique (ReAct)

Pour les questions complexes, Spectra active une boucle de raisonnement : le LLM peut décider d'effectuer plusieurs recherches affinées successives.

04 / Fine-tuning

Spécialisez votre modèle

01Synthèse de Dataset Automatique

Génération automatique de paires Q&A et DPO à partir de vos documents avec garde de qualité Jaccard.

02Fine-Tuning QLoRA (Unsloth)

Entraînement ultra-rapide sur des "modules de mémoire" (LoRA) pour une efficacité maximale sur matériel local.

03Boucle de Rétroaction (DPO)

Évaluez les réponses pour alimenter un nouvel entraînement et affiner les préférences du modèle.

Glossaire technique

Embedding

Traduction d'un texte en une liste de nombres représentant son sens sémantique.

BM25

Algorithme de recherche par mots-clés (statistiques sur la fréquence des termes).

RRF

Méthode mathématique pour fusionner deux classements différents (Vecteur + BM25).

Cross-Encoder

Modèle IA expert qui compare précisément une question et un document pour les trier.

QLoRA

Méthode d'entraînement ultra-efficace qui ne modifie que quelques paramètres du modèle.

ReAct

Stratégie où l'IA alterne entre réflexion et action (recherche documentaire).

06 / Écosystème

Trois projets reliés par MCP

Chaque projet fonctionne de façon autonome. Ils peuvent aussi être lancés ensemble à partir des images Docker publiées.

Kafka SQL Explorer

Explorer Kafka, l'interroger en Flink SQL, l'auditer avec l'IA — et le servir aux agents en serveur MCP en lecture seule. Peut prendre Spectra comme fournisseur de LLM privé.

compagnonsdudev/kafkaexplorer · AGPL-3.0

SpectraLLM · ce projet

Recherche RAG locale, fine-tuning et MCP en lecture seule. Les agents peuvent retrouver un passage, relire la révision citée et parcourir le document. Sur une instance partagée, chaque clé peut être limitée à ses collections.

compagnonsdudev/spectrallm · AGPL-3.0

Kex-anHarness

Un agent IA gouverné qui agit par des outils MCP — il lit Kafka par l'Explorer et cherche dans vos documents par Spectra, sous supervision humaine.

compagnonsdudev/kex-agent-ai · GPL-3.0

Lancer les trois projets

git clone https://github.com/devdownin/Kafkaexplorer.git && cd Kafkaexplorer
docker compose -f compose/spectra-hub.yml -f compose/spectra-hub.mcp.yml \
  -f compose/ecosystem.yml up -d
